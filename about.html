අප ගැන About

නිපුණධම්ම Singlish · singlish.nipunadhamma.org

නිපුණධම්ම Singlish යනු Singlish (ඉංග්‍රීසි අකුරුවලින් ලියන සිංහල) ටයිප් කරලා ඒ වෙලාවෙම සිංහල අකුරු වලට පෙරළලා පෙන්වන නොමිලේ online tool එකකි.

Singlish → සිංහල යනු කුමක්ද?

"sinhala" කියලා ටයිප් කරාම සිංහල, "aayuboowan" කියලා ටයිප් කරාම ආයුබෝවන් විදියට අකුරු පෙරළිලා එනවා. දැනටමත් ලියලා තියෙන Singlish text එකක් පිටපත් කරලා (paste කරලා) ඒක එක පාරටම සිංහලට පෙරළගන්නත් පුළුවන්. Output එක Word, Facebook, WhatsApp වගේ ඕනම තැනකට පිටපත් කරගන්න පුළුවන්.

විශේෂාංග

  • Live preview — ටයිප් කරන ගමන්ම සිංහල අකුරු පේනවා.
  • Sinhala fonts 16+ — FM Abhaya, FMMalithi, 4u Ajantha වගේ legacy FM fonts ඔක්කොම bundle වෙලා.
  • Unicode + legacy encoding — Unicode mode එකේදී output එක හැමදාම standard Unicode; legacy font එකක් තෝරාගත්තොත් ඒ font එකේම legacy encoding එකට පෙරළෙනවා.
  • Font download — ඕනම font එකක් එක click එකකින් download කරගන්න පුළුවන්.
  • Custom font preview — ඕනම .ttf/.otf font file එකක් upload කරලා preview කරන්න පුළුවන්.
  • සම්පූර්ණ keyboard map — ස්වර, ව්‍යංජන, සංයුක්ත අකුරු ඔක්කොම.

එය වැඩ කරන්නේ කෙසේද?

මේක client-side එකක් — converter එක ඔබේ browser එකේම ධාවනය වෙනවා (JavaScript එකෙන්). ඔබ ටයිප් කරන Singlish text එක කිසිම server එකකට යවන්නේ නැහැ, save කරන්නේ නැහැ. ඔබේ fonts තේරීම විතරක් ඔබේ device එකේම (localStorage) ඉතුරු වෙනවා. ඒ නිසා මේක පුද්ගලික සහ ආරක්ෂිතයි.
